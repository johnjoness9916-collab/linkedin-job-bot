# ربات تلگرام استخراج آگهی‌های شغلی ریموت برای شرکت‌های کوچک (LinkedIn Small Companies Remote Job Bot)

این ربات به صورت لحظه‌ای آگهی‌های شغلی لینکدین را بر اساس چندین جستجوی موازی که شما تعیین می‌کنید استخراج می‌کند. 
مهمترین ویژگی این ربات، **فیلتر شرکت‌های کوچک** است. ربات پس از یافتن یک موقعیت شغلی، تعداد دنبال‌کنندگان (Followers) شرکت را بررسی کرده و تنها در صورتی که تعداد آن‌ها کمتر از حد نصاب (مثلا ۱۰۰۰ نفر) باشد، آگهی را به تلگرام شما ارسال می‌کند.

این پروژه نیازی به لاگین در لینکدین ندارد و از Guest API استفاده می‌کند تا احتمال بلاک شدن کاهش یابد.

## 🚀 پیش‌نیازها و راه‌اندازی

### ۱. ساخت ربات در تلگرام
۱. در تلگرام به ربات [@BotFather](https://t.me/BotFather) پیام دهید.
۲. دستور `/newbot` را ارسال کنید و نام و نام کاربری برای ربات خود انتخاب کنید.
۳. توکن (Token) داده شده را کپی کنید.

### ۲. دریافت Chat ID
۱. برای دریافت Chat ID خود، به ربات [@userinfobot](https://t.me/userinfobot) در تلگرام پیام دهید.
۲. عدد `Id` که به شما می‌دهد را کپی کنید.

### ۳. تنظیمات محلی (Local)
۱. فایل `.env.example` را به `.env` تغییر نام دهید.
۲. مقادیر `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` را داخل آن قرار دهید.
۳. فایل `config.json` را بررسی کنید. در این فایل می‌توانید کلمات کلیدی، موقعیت جغرافیایی، زمان بررسی، و حداکثر تعداد دنبال‌کنندگان شرکت (`max_company_followers`) را تنظیم کنید.
۴. کتابخانه‌های مورد نیاز را نصب کنید:
   ```bash
   pip install -r requirements.txt
   ```
۵. برنامه را اجرا کنید:
   ```bash
   python main.py
   ```

## 🛠 امکانات و ساختار فایل `config.json`
- **جستجوی موازی:** ربات می‌تواند همزمان چندین کلمه کلیدی را با فیلترهای مختلف (مثل ریموت بودن و 24 ساعت اخیر) جستجو کند.
- **فیلتر هوشمند شرکت:** بررسی تعداد دنبال‌کنندگان شرکت و رد کردن شرکت‌های بزرگ.
- **کش (Cache) دیتابیس:** ذخیره تعداد دنبال‌کنندگان شرکت در دیتابیس `sqlite` تا از درخواست‌های مکرر به لینکدین و بلاک شدن جلوگیری شود (`company_cache_days`).
- **تأخیر هوشمند (Delay):** بین هر درخواست به صفحه شرکت‌ها، یک تأخیر رندوم وجود دارد.

### نمونه فایل `config.json`
```json
{
  "searches": [
    {
      "keywords": "ai engineer",
      "geoId": "92000000",
      "f_WT": "2",
      "f_TPR": "r86400",
      "sortBy": "DD"
    }
  ],
  "check_interval_seconds": 300,
  "max_company_followers": 1000,
  "company_cache_days": 7,
  "blacklist_words": ["senior", "lead", "manager", "staff", "principal"]
}
```

## 🌍 استقرار روی سرور مجازی (VPS) یا سرورهای ابری
شما می‌توانید این ربات را روی Docker اجرا کنید.
```bash
docker build -t linkedin-bot .
docker run -d --env-file .env linkedin-bot
```

## 💬 دستورات تلگرام
- `/start` : مشاهده وضعیت فیلترها و شروع
- `/status` : مشاهده تعداد آگهی‌های ارسال شده در روز جاری
- `/stop` : توقف دریافت پیام در بات
